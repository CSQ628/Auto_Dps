# DPS 远征助手 · Auto_Dps 1.0.3

DPS Desktop Pension Squad 的本地自动成长助手，支持普通游戏进程和可选的 Sandboxie-Plus 多实例。免费提供源码，仅供学习参考，禁止付费商业用途；允许自行修改和免费分发，详见 [使用许可](LICENSE)。

## 下载与启动

到 [Releases](https://github.com/weixiao030/Auto_Dps/releases/latest) 下载 **Auto_Dps-1.0.3-Windows-x64.zip**，完整解压后双击 `DPSAssistant.exe`。保留同目录下的 `_internal` 文件夹。

发行包已包含运行环境，**无需安装 Python、Node.js、Frida 或 IDA**。需要 Windows 10/11 x64、已安装的游戏和正常的 Steam 环境。助手自动查找 Steam 及其多个游戏库，也可先从 Steam 启动游戏，助手会自动接入。普通单实例无需 Sandboxie；多实例需要自行安装 Sandboxie-Plus 并启动对应沙盒内的游戏。

首次打开控制台显示使用说明，等待 3 秒后才能点击“我同意”。同意记录保存在本机，后续启动不再提示。关闭浏览器后自动化继续；再次双击程序可打开原控制台。助手运行时显示系统托盘图标，双击图标打开界面，右键可暂停／继续或退出助手；也可双击 `停止助手.cmd` 退出，游戏不会被关闭。

## 参数与自动保存

每个自动化模块下直接显示当前参数，可原地调整。“参数设置”集中显示全部 **8 组、39 项**参数及其默认值、范围和用途。

| 分组 | 可调整内容 |
| --- | --- |
| 运行与重试 | 巡检间隔、自动启动、启动重试、动作重试和冷却 |
| 主线与练级 | 推进观察时长、失败次数、死亡回退、练级时长、主线重试、关卡偏移、练级失败降档、候选范围与经验实测选点 |
| 无限塔 | 挑战间隔、练级等待、失败后是否等待战力变化 |
| 装备策略 | 槽位保持时间、淘汰装备回切时间、最低评分提升 |
| 技能成长 | 保留点数、职业推荐组合、未使用技能退款 |
| 符文与预算 | 灵魂与水晶保留预算、永久符文开关、投资偏好 |
| 宠物策略 | 自动切换、成长、战斗或保留当前宠物 |
| 工坊与仓库 | 背包压力、单批回收数量、普通与高品质回收档差 |

数字修改约 0.7 秒后保存，离开输入框立即保存；开关和选项即时提交。非法数值不会写入，保存失败可重试。全部实例共用策略，各账号资源和进度独立计算。支持按组恢复默认值。

配置、同意记录、运行日志和账号备份保存于 `%LOCALAPPDATA%\DPSAssistant`，不放入发行包。特殊安装位置可用 `DPS_GAME_PATH` 环境变量指定完整 `DPS.exe` 路径。

## 自动成长

联动宝箱、三角色逐槽换装、主动技能与被动、符文、角色和宠物、合成、分解、锻造、镶嵌、仓库、邮件、主线 Boss 和无限塔。主线失败后返回已通关的免费关卡练级，成长后重新推进。塔挑战按原生已通层数递进，主线和塔失败分别统计。

换装采用同一次原生整套评分，执行前再次复核；实际战斗面板单独显示原生伤害、DPS、治疗和血量。可交易、锁定、登记和未确认物品受保护；Boss 仅按原生下一关要求使用已核验入场券。DLC 按游戏原生所有权判断。

本机通信支持原生 TCP 与系统通道自动恢复，游戏外网状态单独显示。游戏离线或同步积压时，消费等待，符合原生条件的免费练级可继续。

**1.0.3 已验证双实例自动成长和主要联动，但尚未完成所有长期毕业目标，不能把 5 分钟验证当作全程毕业保证。** 验证范围见 [VALIDATION.md](VALIDATION.md)。

## 从源码运行

开发环境需要 Python 3.10+ 和 Node.js 20+。

```powershell
python -m pip install -r requirements.txt
cd web
npm ci
npm run build
cd ..
python -X utf8 desktop_entry.py
```

```powershell
node --test tests/*.test.cjs
python -X utf8 -m unittest discover -s tests -p "test_*.py"
```

Windows 打包：安装 `pyinstaller==6.15.0` 后运行 `python -X utf8 tools/build_release.py`。脚本同时收集第三方许可并生成 ZIP 与 SHA-256 校验文件。

## 1.0.1 空战场恢复

针对新电脑使用时可能出现的“已保存编队有英雄，但战场英雄未出现”增加恢复检查。持续等待后先调用游戏原生编队同步；仍未恢复才重新进入当前免费关卡。正常死亡不触发，不消耗入场券，不重置账号进度。两项恢复时长在“无人值守接续”模块下可调并自动保存。

若仍异常，在“参数设置 → 运行诊断”导出诊断 JSON。文件不含账号、昵称、存档、文件路径或控制令牌。本修复已做条件测试和本机验证；玩家反馈现场仍需回访确认。

切场确认期间会暂停其他切场提交。结算后长时间无波次、生成和入场变化时，按可调阈值检查；只有原生通关统计一致且下一关免费，才直接接续下一关，否则只重入当前免费关卡。收费入场结果未知时不自动重放。


## 1.0.2 练级选点与切场确认

主线与练级模块新增实测选点：只比较免费、已通关且可重复的关卡，按队伍中经验收益最低的角色计算经验/分钟。达到最少有效观测时长并确认通关后，才探索下一个候选；比较结束后，收益超过设置比例才换点。等级、装备、技能、符文或宠物变化会重新测量，暂停、离线、可见面板、切场和塔战不混入采样。换点等待结算或下一轮开始，主线重试仍按原设置执行。

收费切场回执丢失或超时后保留目标预约，短暂消失的操作或入场物品 UID 变化不会导致重复提交。仅原生到达或通关证据解除预约。到达确认同时核对类别、关卡、难度和英雄就绪状态。

运行诊断增加快照延迟、原生战斗结果和待确认切场目标，便于排查“结算卡死、回到 1-1”。玩家反馈现场尚未复现；本机验证不等于所有电脑或全程毕业验证。


仓库合成会同时规划所有满足原生配方的材料组，仓库取料需要开启“仓库调度”；合成模块会显示取料、空位或配方条件。分解等待原因显示在运行记录中，参数设置可导出脱敏诊断。主动技能按当前五种英雄的原生技能类型和解锁等级规划；未拥有的两名 DLC 英雄仅完成配置与回归测试，尚无实机战斗验证。


助手会检查公开发行版，在页面提示可用更新；下载并完整解压后，先退出旧助手再打开新版本。启动新包时若后台仍在运行旧版，会明确提示。检查更新失败不会阻断游戏自动化。


## 1.0.3 开箱接续与托盘

背包满且需要仓库材料时，先把可安全移动的物品临时存仓，保留当前配方已经持有的材料，再取料、合成并接续开箱；仓库也没有空位或调度已关闭时等待原生条件。不会为腾位删除物品或绕过保护条件。

新增 Windows 托盘和分解等待原因。运行中的更新提示从本版本开始提供；1.0.0～1.0.2 无法自行获得这段检测代码，需要先手动下载、完整解压并启动新包，新包会提示后台仍在运行的旧版。
