# DPS 远征助手 · Auto_Dps 2.0.0

DPS Desktop Pension Squad 的本地自动成长助手，支持普通游戏进程和可选的 Sandboxie-Plus 多实例。免费提供源码，仅供学习参考；禁止付费商业用途，允许修改和免费分发，详见 [使用许可](LICENSE)。

## 下载与启动

到 [Releases](https://github.com/weixiao030/Auto_Dps/releases/latest) 下载 **Auto_Dps-2.0.0-Windows-x64.zip**，完整解压后双击 `DPSAssistant.exe`，保留同目录的 `_internal` 文件夹。

发行包包含运行环境，无需安装 Python、Node.js、Frida 或 IDA。需要 Windows 10/11 x64、游戏及正常 Steam 环境。普通单实例无需 Sandboxie；多开需要先安装 Sandboxie-Plus 并启动沙盒中的游戏。

升级前先退出旧助手，再将新版完整解压到独立目录。配置、参数、日志、同意记录和账号备份保存在 `%LOCALAPPDATA%\DPSAssistant`；无需复制旧程序目录。启动新包时，若后台仍有旧助手会提示先退出。

首次打开请阅读说明，等待 3 秒后点击“我同意”。关闭网页后助手继续运行；再次双击打开原控制台。托盘右键可暂停、继续或退出，`停止助手.cmd` 也可退出助手，不会关闭游戏。

## 自动连接与手动绑定

自动发现 Steam 多游戏库、普通进程及 Sandboxie 实例。每个账号独立规划，重复账号只允许一个实例提交动作。

右上角“连接游戏”支持重新扫描、选择运行实例、填写 PID，以及保存游戏目录或 `DPS.exe` 完整路径。路径必须包含游戏执行文件、原生程序集和元数据；进程绑定会核对进程名、创建时间和存活状态，拒绝失效 PID。运行实例的手动绑定随进程寿命失效，自动发现继续保留；指定安装路径保存在本机，用于后续自动启动。

## 2.0 控制台

- 远征概览：当前实例、正在处理的任务、队伍、每页仓库占用与近期记录。
- 自动化策略：16 个模块独立启停，展开后查看相关设置。
- 沙盒与实例：查看普通与沙盒连接、单独启停及手动绑定。
- 运行记录：区分等待、提交、待结算和实际确认，显示整理等待原因。
- 参数设置：8 组、46 项设置，提供用途、例子、默认值和范围，支持亮暗主题与窄屏。

数值停止输入约 0.7 秒后自动保存，失焦立即保存；开关和选项即时保存。保存失败保留输入并可重试，分组可恢复默认。全部实例共用策略，各账号资源与进度分别计算。

## 手动窗口如何共存

默认保留你打开的背包、仓库、英雄、方块和符文窗口。兼容成长继续，与当前窗口冲突的动作等待；例如查看仓库时技能和符文可以继续，存取、换装、工坊和切场等待。查看英雄时其装备和技能变更等待，其他兼容动作继续。

“查看游戏窗口时暂停全部操作”默认关闭，开启可恢复严格暂停模式。关闭对应窗口后自动恢复。正在拖拽物品、未知确认弹窗会暂停提交；交易窗口及手动方块材料阻止物品和切场冲突操作。关闭“保留手动打开的背包等面板”后，允许助手按原生关闭流程收起已知面板。

## 多页仓库与物品整理

扫描全部已解锁仓库页，按页接收规则寻找空位；背包与仓库整理阈值分别可调。例如两页共 98 格、阈值 80%，达到 79 格即开始安排仓储整理。

优先保留每个角色的换装与后续等级候选、完整配方材料，已就绪合成和合成取料先于分解。两个容器都满时，尝试原生槽位交换取料；没有安全组合则等待并说明原因。

空间紧张时可回收已证明没有换装和完整配方用途的当前档闲置装备，品质上限可调。交易、锁定、登记、镶嵌和未确认物品继续受消费保护；可交易装备可以安全换装和存取。

物品处理结束后，使用游戏原生背包排序及逐页仓库排序，不切换当前页。排序会核对数量、品质关联配置、交易属性、确认状态、锁定和镶嵌；普通堆叠允许原生合并，受保护物品保留 UID。若受保护堆叠会被合并，该页等待手动整理；无布局变化时不反复排序。

## 自动成长与关卡

包含宝箱、逐角色整套评分换装、主动组合与技能点、被动前置、符文预算、角色编队、宠物偏好、合成、分解、锻造、镶嵌、邮件与离线收益、主线推进、练级和无限塔。

动作执行前重新读取原生前置和账号状态，提交不等同成功。主线和塔失败分别统计；练级只选择免费已通关关卡，按连续经验与原生通关证据比较收益，战力变化重新采样。收费切场回执不明时保留预约，不自动重放。

默认灵魂可用于成长，水晶保留 2 个；可关闭永久符文消费或提高保留预算。DLC 按原生所有权判断。游戏离线或同步积压时成长消费等待，符合原生条件的免费恢复与练级可继续。

本机健康连接支持两种直连通道恢复，显示桥接启动阶段和扫描耗时。参数设置可导出脱敏诊断，不含账号、昵称、路径、存档和控制令牌。

验证范围见 [VALIDATION.md](VALIDATION.md)。本机双实例及回归测试不代表所有电脑、所有沙盒配置、最优练级或全系统毕业均已验证；未拥有 DLC 英雄主要通过原生配置和夹具回归覆盖。

## 从源码运行

开发需要 Python 3.10+、Node.js 20+：

```powershell
python -m pip install -r requirements.txt
cd web
npm ci
npm run build
cd ..
python -X utf8 desktop_entry.py
```

```powershell
node --test tests/*.test.cjs
python -X utf8 -m unittest discover -s tests -p "test_*.py"
```

Windows 打包：安装 `pyinstaller==6.15.0` 后运行 `python -X utf8 tools/build_release.py`，生成 ZIP、SHA-256 和第三方许可。
