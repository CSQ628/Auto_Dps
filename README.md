# DPS 远征助手 · Auto_Dps 2.2.32

DPS Desktop Pension Squad 的本地自动成长助手，支持普通游戏进程和可选的 Sandboxie-Plus 多实例。免费提供源码，仅供学习参考；禁止付费商业用途，允许修改和免费分发，详见 [使用许可](LICENSE)。

## 下载与升级

当前版本 **2.2.32**：[下载 Windows x64 便携包](https://github.com/weixiao030/Auto_Dps/releases/download/v2.2.32/Auto_Dps-2.2.32-Windows-x64.zip)，[更新说明与 SHA-256](https://github.com/weixiao030/Auto_Dps/releases/tag/v2.2.32)。

退出旧助手，将新版完整解压到独立目录，运行 `DPSAssistant.exe`，保留 `_internal` 文件夹。无需安装 Python、Node.js、Frida 或 IDA。需要 Windows 10/11 x64、已安装游戏和正常 Steam 环境；多开可选 Sandboxie-Plus。

配置、参数、日志、同意记录和账号备份保存在 `%LOCALAPPDATA%\DPSAssistant`，升级自动沿用，无需复制旧程序目录。首次启动阅读说明并等待3秒同意；关闭网页后助手继续运行。托盘和 `停止助手.cmd` 可退出助手，游戏不会退出。

## 本版更新

- 自动开箱增加传输重试和持续退避；明确尚未执行的请求自动接续，消费结果未知时查询原生回执，防止重复开箱。各账号恢复独立，日志故障或任务异常不再关闭自动化，保留玩家主动暂停。
- 全部16模块细分为173项参数。装备、饰品、精炼材料和制作材料可分别配置合成品质、档位与优先级；原有基础参数默认值和玩家设置沿用。
- 自动直接整理背包与所有已解锁仓库页，按可执行的锻造 > 合成 > 分解联动。空间紧张时先腾出一批空位再恢复开箱，缺料、冷却或待确认不阻断其他独立工作。
- 装饰、宝石和纹章支持合成升品质，完整批次先保留，余量用于镶嵌。不朽及以下装备优先为高品质装备补空槽，保留已有镶嵌与交易属性。
- 制作、合成、镶嵌、存取仓库等使用持久回执，恢复旧版等待；逐项核验消耗与产物，不凭超时重复消费。
- 每个账号按实时等级、职业、解锁、工坊等级和当前上阵英雄计算目标。完善镶嵌效果与成长联动、扩容对经验采样的影响，以及完整练级轮次结算后再比较地图。

全部参数及保存键见 [PARAMETERS.md](PARAMETERS.md)，回归和实机验证范围见 [VALIDATION.md](VALIDATION.md)。

## 自动化与自定义

- 自动识别普通与沙盒游戏；“自定义多个连接”支持选择进程、填写PID或保存游戏安装目录。同账号只允许一个实例提交，账号资源、回执、冷却及进度分别计算。
- “自动化策略”有16个独立模块，展开后编辑子功能；“参数设置”可搜索全部173项。数值停止输入约0.7秒后保存，失焦立即保存，开关即时保存；保存失败保留输入并支持重试。
- 默认灵魂、灵魂石和技能点预留均为0，预算可以自定义。主动、被动和刻印按原生前置投入；逐点退款核验后纠错，原生不允许时等待资格恢复。
- 只为当前上阵前三名英雄自动换装、制作和镶嵌，保留阵容及手动选择。缺料配方只按需求数量保留，多余材料可以继续合成。
- 跨所有已解锁仓库页取料、存放、排序和满仓交换；取料继承对应工序优先级。工坊使用原生配方与实际容量，消费前重新检查材料及数量。
- 交易、锁定、登记和未确认材料受消费保护。锁定装备允许无损存取，穿在身上时不自动替换；带镶嵌旧装备默认保留，可配置授权回收，分解后镶嵌不返还。
- 不朽及以下可交易装备补镶嵌默认开启；高品质装备及材料优先，只填空槽，保留已有镶嵌。精炼材料合成和装备镶嵌分别使用合成、精炼模块。
- 物品处理后直接调用原生背包及逐页仓库排序，保留当前页。未知消费预约持续核对回执，独立工作继续。
- 主线失败后自动练级并在成长后重试。选图按实际经验与完整结算比较，等级与关卡上限来自当前游戏目录，不固定作者账号等级。无限塔独立开关，关闭后不自动开启。
- 默认收起已知背包、仓库和成长窗口，可关闭自动收起；拖拽、交易、方块留料和未知确认弹窗按实际冲突等待。异常写日志并重试，玩家主动暂停仍优先。
- 已拥有宠物的加成同时生效；跟随仅改变显示，保留玩家选择，空缺才补齐。

## 源码构建

使用 Python 3.10 与 Node.js 22：

```powershell
python -m pip install -r requirements.txt pyinstaller==6.15.0
cd web
npm ci
npm run build
cd ..
python -X utf8 -m unittest discover -s tests -p "test_*.py"
node --test tests/*.test.cjs
python -X utf8 tools/build_release.py
```
